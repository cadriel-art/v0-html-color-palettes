# Contributing

Thanks for your interest in contributing!

- Suggest new palettes by opening an issue or PR with palette name, hex codes, and a short preview image (optional).
- For code or doc changes:
  1. Fork the repo.
  2. Create a branch: git checkout -b feature/my-change
  3. Make your changes and run the dev server to verify.
  4. Commit and push, then open a pull request describing your change.
- Be sure your PR includes a short description and screenshots if it affects UI.
- Follow the Code of Conduct (see CODE_OF_CONDUCT.md).
